hwval SegDocument · YML Config Generator

Build a hwval.yml for SegDocument without hand-editing YAML. Add fields, scope them to a report, and copy the output straight into your project.

1.Fields

Each field becomes a column in the rendered .docx. Plain string entries (no reports) appear in both reports; entries with reports are scoped to a single report. Drag the handle to reorder. Field names must be valid Python identifiers (letters, digits, underscores; not starting with a digit).
